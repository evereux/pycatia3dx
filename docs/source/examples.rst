Hybrid Shape Factory - Example 1
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Sequentially rename all points in geometric set (Hybrid Body) Points in the
geometric set MasterGeometry.

`Hybrid Shape Factory - 001 <https://github.com/evereux/pycatia3dx/blob/main/examples/example__hybrid_shape_factory__001.py>`_


Hybrid Shape Factory - Example 2
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Creates a new 3DShape and reads a csv file containing point data and adds to the
new 3DShape.

`Hybrid Shape Factory - 002 <https://github.com/evereux/pycatia3dx/blob/main/examples/example__hybrid_shape_factory__002.py>`_


Hybrid Shape Factory - Example 3
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Creates a new 3DShape, creates two points and draws a line between them.

`Hybrid Shape Factory - 003 <https://github.com/evereux/pycatia3dx/blob/main/examples/example__hybrid_shape_factory__003.py>`_


Hybrid Shape Factory - Example 4
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Loops through the items in hybrid body "ConstructionGeometry" and determine the
object type using selection. Once determined create an object from it and find
its parent(s).

`Hybrid Shape Factory - 004 <https://github.com/evereux/pycatia3dx/blob/main/examples/example__hybrid_shape_factory__004.py>`_


Hybrid Shape Factory - Example 5
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Split a surface using a plane.

`Hybrid Shape Factory - 005 <https://github.com/evereux/pycatia3dx/blob/main/examples/example__hybrid_shape_factory__005.py>`_
